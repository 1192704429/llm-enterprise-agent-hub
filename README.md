# 基于Spring AI与DeepSeek大模型的企业智能办公Agent系统的设计与实现

> 本文基于Spring AI、DeepSeek大模型、Vue 2及Qdrant向量数据库，围绕企业智能办公场景，设计并实现了一套具备多端协同、知识库问答、智能审批与日程管理能力的企业智能办公Agent系统。

## 一、项目背景

随着企业数字化转型的深入，传统办公系统面临信息检索效率低、审批流程繁琐、知识管理分散、员工自助服务能力不足等问题。员工在日常工作中需要频繁查询公告、请假状态、审批进度、日程安排等信息，而管理员也需要高效维护企业知识库、管理组织架构并配置大模型服务。基于大语言模型的智能办公Agent系统，通过自然语言交互方式，将企业知识库问答、公告查询、员工信息查询、请假提交与查询、审批查询、日程查询、知识库文件查询及AI生成公告等能力整合到统一平台中，有效降低办公操作门槛，提升企业运营效率与管理水平。

## 二、功能模块介绍

本系统划分为管理员端与员工端两个子系统。管理员端面向企业管理者，提供企业知识库维护、智能办公Agent管理、对话记录查看、数据统计、组织架构管理及大模型配置等能力；员工端面向普通员工，提供智能办公对话、系统公告查看、请假管理、审批查看、日程管理及个人中心等功能。系统角色与所属端对应关系如下表所示：

| 角色名称 | 所属端 | 核心职责 |
|---------|--------|---------|
| 管理员 | 管理员端 | 登录、仪表盘、知识库管理、Agent管理、对话记录、数据统计、员工管理、部门管理、公告管理、大模型配置 |
| 用户 | 员工端 | 登录、智能对话、系统公告、请假申请与查询、审批查询、日程管理、个人中心 |

## 三、技术栈说明

前端：Vue 2 + Element UI + ECharts，用于构建管理员端与员工端界面，ECharts用于数据统计图表可视化展示。

后端：Java 17 + Spring Boot 3.4.5 + Spring AI，Spring AI作为大模型集成框架，对接DeepSeek及OpenAI大模型接口，实现智能对话与Agent能力调度。

数据库与中间件：MySQL存储业务数据，Redis提供缓存加速，Qdrant作为向量数据库支撑企业知识库语义检索，Python FastAPI用于文档解析服务，实现知识库文件的解析与向量化处理。

## 五、主要业务流程

1. 管理员登录系统后，进入大模型配置模块，配置DeepSeek或OpenAI的API密钥、模型名称及参数。
2. 管理员在企业知识库模块上传企业文档，Python FastAPI文档解析服务对文件进行解析处理。
3. 文档解析完成后，系统将文本内容向量化并存储至Qdrant向量数据库，构建企业知识库索引。
4. 员工登录员工端后，在智能办公对话模块输入自然语言查询请求。
5. Agent接收请求后，通过Spring AI调用大模型接口，并进行意图识别与实体抽取。
6. 系统根据意图从MySQL、Redis或Qdrant中检索相关数据，并将上下文返回给大模型。
7. 大模型生成回答结果，系统将结果展示给员工，并将对话记录保存至数据库。
8. 员工发起请假申请时，Agent引导员工输入请假类型、起止时间及事由，并调用后端接口提交请假单。
9. 管理员在管理员端通过数据统计模块查看对话量趋势、知识库使用情况等统计图表。
10. 系统定期将对话记录与统计数据写入MySQL，并通过Redis缓存高频查询数据，提升系统响应速度。

## 六、项目拓展性

本系统基于Spring AI框架与模块化设计，具备良好的扩展能力。未来可接入更多大模型服务商，扩展多模型路由与智能切换能力。企业知识库可支持更多文档类型与自动更新机制，结合Qdrant实现增量向量化与知识自动更新。智能办公Agent可扩展至更多办公场景，如智能会议安排、智能考勤统计、智能财务报销、智能客户管理等。同时，可引入消息推送机制，与钉钉、飞书、企业微信等办公平台集成，实现移动端消息通知与审批提醒。员工管理与部门管理可进一步扩展至权限管理模块，实现细粒度的数据权限与操作权限控制，满足中大型企业组织架构的复杂管理需求。
